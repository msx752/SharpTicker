# API reference

Generated from the source code and its XML documentation comments, for the .NET 10 build of every package. The .NET 8 and 9 builds have the same public API.

Start with:

- `SharpTicker.DependencyInjection`: `AddSharpTicker`, `UseSharpTicker` and code-first `MapTicker` registration.
- `SharpTicker.Utilities.Base`: `TickerFunctionAttribute` and `TickerFunctionContext`.
- `SharpTicker.Utilities.Interfaces.Managers`: `ITimeTickerManager<T>` and `ICronTickerManager<T>`.
- `SharpTicker.Utilities.Entities`: `TimeTickerEntity` and `CronTickerEntity`.
