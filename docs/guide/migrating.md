# Migration guide

The guide for moving an existing application to SharpTicker is kept next to the code, in [MIGRATING.md](https://github.com/msx752/SharpTicker/blob/main/MIGRATING.md).

It covers package and code changes, what happens to stored jobs, how to switch instances, and a prompt for AI coding assistants.

For an upgrade from one SharpTicker version to another, see [Upgrading](upgrading.md).
